## 从五图代码学习并吸收的内容

阅读了 ZIP 中的《生成五图成果.py》、统计结果与验收代码，查看旭日、人物华夫、桑基、四象限、雷达五张成图。仅提取必要文件到本地检查目录，未运行其中的生成/验收命令，原 ZIP 保持原样。

1. 分层旭日：父子数量守恒、扇区角度闭合、稳定的颜色和纹理；小标签用代码与侧栏完整释义对应。
2. 人物华夫：一图标一分析单位，稳定排序、回数核对；“未明确”单列，整数案例不能四舍五入制造人物。
3. 三列桑基：使用真实联合记录，核对每列节点与两段流量；相邻边际表不能拼造三列个体联属，流线不自动表示因果。
4. 四象限：阈值口径明确，重合点保持原坐标并合并标注，允许真实空象限；频次和覆盖不能直接当作重要性。
5. 雷达：固定各群体分母及0—100%尺度，用线型、符号、颜色冗余区分；未谈及不等于反对，不能从多边形面积推导总体评价。

已加入 [访谈五图方法参考](../skills/make-model-figures/references/interview-figure-patterns.md) 和制图 skill 的按需路由，人物华夫已落成可调用代码。其余四图主要吸收数据、布局和审核方法，复用已有图型能力，未另行宣称新增四个入口。

原程序的固定用户路径、固定字体文件和统一填写 PASS 的 `finalize()` 没有照搬。原始访谈全文未在本轮重新取得，因此没有声称复核其全部编码。

## 流程、赛事与兼容

契约升级为1.5、状态为1.2；保留旧1.1—1.4契约及1.0/1.1状态读取。旧状态推进前显式选择 venue；CUMCM兼容旧版式角色，其他赛事使用通用 `layout_validation`。

阶段门检查实际报告状态、逐问结果和质量要求。审稿输入在进入 review 时提供；审稿、预检和就绪结果在进入 release 时提供。失败诊断保留，文件齐全但校验失败不能通过。`rewind` 保留实体文件及历史，将目标及下游结果标为过期；旧状态从转移历史推断证据阶段，无法推断的重新核验。competition 保存关键登记项哈希，audit 保留更强复核；独立第二轮审查的强度随 profile，不把重复提及同一问题计为多个问题。

未指定赛事使用通用报告。状态与配置的赛事冲突明确拒绝。通用报告不强制国赛页数、匿名、AI详情或支撑包；显式提供的支撑包仍严格复算。数量下限只执行项目明确声明的要求，优化术语只检查相应题型，正式正文不要求显示后台 claim 标记。

CUMCM规则依据 [2026论文格式规范](https://www.mcm.edu.cn/html_cn/node/4cd596519c9eb9fbd866398f6df0caa3.html) 和 [2026 AI使用规定](https://www.mcm.edu.cn/html_cn/node/fef94648f2836ab6cc81586f4c38512b.html)。官方写20 MB，本库保守按20,000,000字节配置；宋黑字体、行距等是本地风格，不能称为官方强制要求。

## 安装与使用

八个skill已更新到 `C:/Users/Blake/.codex/skills/`。更新前副本保存在 `output/practical-validation/skill-backup/`；用户算法包旧文件另存 `algorithm-backup/`。仅更新本库八个skill及算法包，其他skill未覆盖。

人物华夫调用示例：

```python
from algorithms.figures import get_figure

fig = get_figure("pictogram")(
    mode="preview",
    data={"categories": ["支持", "保留", "质疑", "未明确"],
          "values": [18, 12, 1, 9], "icon_value": 1,
          "pictogram_mode": "array", "array_layout": "waffle",
          "simulated": True})
```

此处数字仅为模式演示；真实分析需传入保存的实际计数、统计单位与来源，正式图再按源值、导出和最终插入逐项审核。可用已安装运行时执行 `scripts/practical_examples.py` 重建16组模拟图。
