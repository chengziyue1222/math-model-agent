## 图表接口与真实行为

保留 164 个注册入口，其中 159 个专用实现、5 个兼容别名。入口统一接受 `get_figure(name)(data=saved_results, config=figure_config, mode="formal")`。样式与数值输入分别解析，配置优先级为显式参数、显式配置或最近项目配置、内置默认。明确传入 `{}` 使用内置默认；文件配置及实际渲染器均保存 SHA-256。

新默认主题为 `cumcm-research`，仍可明确选择旧主题或项目颜色。默认宽度 150 mm，高度按标签、面板与图型调整；正文 8.5 pt、刻度与图例 8 pt、审查下限 7 pt。中文使用字体解析器，西文与数学符号统一。颜色、色标、字体、线宽、标记、尺寸和网格在渲染前生效，独立调用不污染后续图的全局配置。用户自定义 Colormap 可序列化后恢复，显式颜色优先于项目语义颜色。

修复雨云图原来仅画小提琴的语义问题：现在包含半密度、四分位箱线和所有原始点，常数与单点组保留样本但不估计密度。`correlation_matrix` 从成对关系复合图改为真正的 Pearson 相关矩阵，固定 [-1, 1] 色域，常数列标为未定义；原复合视图继续使用 `pairgrid`。KDE 拒绝不足两点或常数样本，避免用数值扰动制造密度。这些是明确登记的语义修正，不能称作完全不变的纯美化。

组成图、人物图与日历饼图增加纹理冗余；人物余量的面积裁剪、气泡面积、真实分母与缺失状态保留原有数值口径。几何图修复 tuple 点索引被误当作二维数组索引的问题，直接 Python 输入和 JSON 输入一致。

长标签案例保留完整名称并同步节点引用；密集案例增加类别、变量、观测和面板，而不是重复普通示例。每个入口分别交付普通、长中文标签、密集三类输入、PDF、SVG、450 DPI RGB PNG、灰度与物理校样。实际审查使用导出的成品；未查看的项目保持 NOT_CHECKED。

## 八个 skill 与证据闭环

| Skill | 本次改动 |
|---|---|
| run-modeling-project | 逐问规划结果、验证和图表用途；赛事规则按 venue 配置；返工使下游证据过期。 |
| analyze-model-data | 绘图交接保存完整对象、单位、分组顺序、统计单位、分母和缺失处理。 |
| select-model | 明确候选、公平基线、验证方案及各结论需要的证据。 |
| solve-model | 交付完整逐期对象和实际情景值，让约束、基线和稳健性检查可复算。 |
| research-model-literature | 国奖身份与论文正文分别核验，图表设计参考与模型事实来源分开。 |
| make-model-figures | 接入共享配置、主题、尺寸与布局，登记每图的五项实际检查。 |
| write-model-paper | 从保存结果生成图表，核对摘要、正文、表格和图注，并查看最终页面。 |
| review-model-paper | 分开列数学证据、图表表达与版面缺陷，修复后检查对应成品。 |

复用契约 1.5、状态 1.2 与现有 schema 3 图表记录，没有新增平行登记系统。输入、渲染器源码或输出哈希变化时拒绝复用图表 PASS；任何 FAIL 保留失败状态。清理了雨云图与相关矩阵的过期能力说明、旧字体下限，以及 competition 与 CUMCM 的默认规则混用。CUMCM 默认文件上限按 20,000,000 字节配置，仍须核对适用年份的官方规则。
