# Academic 风格图表适配记录

本次图表库优化参考了本机目录 `E:/ai数模/academic-data-visualization-main` 的公开 Skill 组织方式和图型示例。该目录声明使用 Apache-2.0；本仓库只保留独立重写的 Matplotlib 实现，不把外部示例数据当作研究数据。

## 已接入的实现

`code/algorithms/figures/academic_style.py` 增加了以下可复用模式：

- 分组柱状图 + 原始点 + 误差语义
- 多模型 AUROC
- 相关矩阵（对角密度、下三角散点、上三角相关系数）
- 雷达图、山脊图、气泡散点、相关气泡矩阵
- 正负边网络图、加权弦图、轨迹图、Mantel 关联图

这些实现已接入注册表，仍使用原来的英文稳定键和中文显示名。新的精选成品脚本 `scripts/build_academic_style_showcase.py` 用相同视觉原则生成 24 个可发给别人预览的 PNG/PDF/SVG 图件，并保存 `.figure.json` 审计元数据。

## 视觉原则

- 白底、低饱和主体色、单一强调色；
- 同一概念跨面板保持同一颜色；
- 用原始点、误差带、椭圆、直接标签补充均值或摘要；
- 多面板按“总览 → 偏差 → 关系”组织，避免只换图型而重复同一信息；
- 随机预览明确标记为合成数据，不可作为真实结论。
