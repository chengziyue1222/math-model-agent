# 数学建模 Skill 库完善方案：实用图表与论文证据交接

日期：2026-10-11。本文替代此前仅侧重流程与质量校验的改进方案，保留其中必要修复，并补充实际会用的图表能力。本轮交付为方案，代码实施另行开展。

## 1. 目标、现状与边界

保留现有 8 个 skill 名称和入口，以完整建模与论文质量为主目标，国赛优先，兼容其他赛事。将用户提供的“高级图表.pptx”作为图型和布局参考，按真实建模用途落实功能。

目前已有散点、抖动散点、气泡、线性回归趋势、基础日历热图、矩阵热图、相关气泡矩阵、混淆矩阵等能力。矩阵迷你折线、极坐标堆叠图、人物图标比例，以及日历或矩阵单元格中的组合小图尚无对应专用入口。基础图、组合布局、统计计算分别维护，避免通过注册别名把缺失功能计为已完成。

采用两个并行的质量目标：图表真实地呈现保存的数据与模型结果；最终页面便于阅读和比较。正式图沿用 PDF/SVG 主文件、450 DPI PNG 校样及 `.figure.json`。预览数据明确标为模拟，真实论文图需要来源和视觉检查。

默认实现静态论文图与报告图，复用 Matplotlib 和现有注册、配置、导出体系。交互式缩放、悬停、动态图形变换留作后续独立阶段，本轮不引入网页图表运行时、不修改 Web 演示。

## 2. 图表专项：按用途复用、扩展和新增

### 优先级与功能清单

| 优先级 | 实际用途 | 对应图型与入口 | 本轮动作 |
|---|---|---|---|
| P0 | 结果、误差、分组或比例比较 | 现有散点、抖动、气泡、百分比堆叠柱、热图 | 复用并核对统计含义、尺度、标签和数据映射，提供用途明确的示例 |
| P1 | 多地区、多供应商、多方案的时序比较 | 矩阵迷你折线 `sparkline_matrix` | 新增行列矩阵布局，按单元格绘制时间序列 |
| P1 | 周期类别或环形分组的组成比较 | 极坐标堆叠图 `polar_stacked_bar` | 一个入口支持径向柱与环向条两种编码，分别形成可检查示例 |
| P1 | 人数、调查比例、情感组成等直观表达 | 人物阵列与人物轮廓比例图 `pictogram` | 一个入口支持阵列和单轮廓分段模式，保留精确数值标签 |
| P1 | 日、周、年度活动、需求或风险分布 | 现有 `calendar_heatmap` | 增加明确的横向/纵向年度布局、月份提示、缺失日期图例 |
| P1 | 变量关系与不同量纲的协变结构 | `correlation_heatmap`、`covariance_heatmap` | 新增明确命名入口；不改变旧 `correlation_matrix` 的行为 |
| P2 | 地区×时期或对象×方案的组成比较 | 饼图矩阵 `matrix_pie` | 新增网格饼图，使用共享分组顺序与图例 |
| P2 | 日期上的数量或组成比较 | `calendar_glyphs` | 在日历单元格嵌入气泡或饼图，复用布局与来源记录 |
| P2 | 回归或机理关系展示 | `regression_curve` | 接受已保存的拟合曲线；线性、指数、多项式拟合留在计算层 |
| P2 | 单轴分布与打卡频次展示 | 现有抖动/原始点图、`bubble_matrix` | 增加单轴布局选项和通用频次气泡矩阵 |

这里的优先级按本次项目用途安排，不代表所有赛题都必须使用这些图。

### 最小输入与具体行为

- `sparkline_matrix`：接受 `row_labels`、`column_labels` 和按行列位置组织的 `series`；每条序列包含 `x`、`y`。空单元格显示缺失状态。相同单位默认共享纵轴，独立尺度必须显式选择并标明；不自动平滑、插值或截取代表性数据。
- `polar_stacked_bar`：接受 `categories`、`groups`、二维 `values`；`orientation="radial"` 表示沿半径堆叠，`orientation="angular"` 表示各环沿角度堆叠。默认展示非负原始量，共享量值标尺；百分比模式显式归一化并记录分母，零总量类别显示无组成。类别、分组与配色顺序稳定。
- `pictogram`：接受类别与非负数值，使用 `mode="array"` 或 `mode="silhouette"`。阵列明确每个图标代表的数量及不足一个图标的余量；余量通过按可见面积裁剪表达，不静默四舍五入。轮廓分段默认按高度编码，显示比例标签并说明高度口径；不把轮廓填充面积称为比例。精确方案差异优先使用点图或条形图，人物图保留为直观说明。
- 日历类：以解析后的实际日期定位，跨年和闰日正常呈现，缺失日期与数值零分开。保留现有重复日期拒绝行为；需要日聚合时由上游显式选择聚合方式并保存结果。`calendar_glyphs` 的饼图模式还需 `groups` 和日期×分组数值，气泡模式声明面积标尺。
- `matrix_pie`：接受行列标签、分组标签及行×列×分组数值。共享图例，扇区使用同一分组顺序，零总量单元格不绘制虚假组成；需要比较总量时增加总量标签，不默认让饼图大小暗示总量。
- 相关与协方差热图：计算辅助函数接收原始观测及明确的缺失处理策略，输出矩阵、标签、样本口径、方法及单位；渲染器接受保存后的矩阵。相关色域固定为 [-1, 1]，常量变量相关值记为未定义；协方差保持原单位乘积，不隐式转成相关矩阵。
- `regression_curve`：接受观测 `x/y` 与保存的 `curve_x/curve_y`，可选真实 `lower/upper/interval_kind`。不在绘图时自动挑选拟合模型，不生成未经计算的置信带；外推区间显式区分。
- `bubble_matrix`：接受行列标签及非负二维数值，气泡面积与量值对应。提供大小图例；为可见性设置的最小面积必须说明，不能继续声称严格比例编码。

新增入口继续通过 `get_figure/get_spec/list_figures` 提供中英文名称；使用现有 `data=`、形式校验、数据契约及 formal/preview 模式。复杂图缺少结构化字段时明确报错，不退回一维数值的通用占位图。

## 3. 八个 Skill 的职责与交接改进

| Skill | 具体调整 |
|---|---|
| `run-modeling-project` | 维护逐问结果与依赖；提前确定图表所需数据；统一档位、赛事、回退和最终交付 |
| `analyze-model-data` | 保存时间、分组、单位、类别顺序及缺失处理；完成日聚合和基础诊断，正式预测或决策模型进入求解阶段 |
| `select-model` | 将结果的证据形态写进模型方案，例如预测对应时序与误差、周期组成对应极坐标；图型不替代选模论证 |
| `solve-model` | 输出各对象和情景的完整结果、基线、终止状态、拟合曲线及已计算的区间；不只输出几个摘要数字 |
| `research-model-literature` | 外部参数与具体主张建立来源指针；分开验证来源身份和内容支持；无需为普通图型制造引用 |
| `make-model-figures` | 按比较、趋势、组成、关系、日历、矩阵小图等信息任务路由；执行专用渲染与成品检查 |
| `write-model-paper` | 从保存的数据和图表解释结果；统一正文、摘要、图注和表格数字；选择必要图表并保持全文配色语义一致 |
| `review-model-paper` | 检查逐问覆盖、图表数值与语义、最终版面；给出最早需要返工的阶段并验证修复闭环 |

保留现有 `decision_contract`、`result_object`、`quality_validation`、`evidence_index` 和图表元数据，不创建另一套平行登记系统。图表计划最少说明：对应问题或结论、数据路径与字段、图型、单位、转换、视觉检查状态。无需每个问题或阶段都生成固定数量的图。

`SKILL.md` 保留任务边界、路由与必要约束；新增图型的字段、示例和特殊语义放到按需读取的 references。绘图实现统一放进算法包，避免仓库、安装目录和 skill 脚本各维护一份。

## 4. 保留并落实上一版的基础修复

### 阶段推进与失败回退

- 阶段门读取实际验证结果，复用逐问契约、质量和提交预检验证器。文件存在或程序退出码为零，只证明对应执行条件，不证明模型正确或论文可提交。
- 缺少必要证据、验证失败、求解不可行却宣称最优、或关键产物过期时，阻止相应完成声明；保留失败记录和诊断。探索性结果仍可形成有明确局限的工作稿。
- 进入 `review` 只要求稿件、渲染产物与审查输入；审稿报告和就绪结论属于进入 `release` 的条件，避免审稿前要求审稿已完成。
- 增加 `rewind --to <stage> --reason <text>`，退回当前或更早阶段。保留历史及仍有效的输入，撤销目标阶段与下游完成标记，标记受影响输出为过期，保留实体文件。重新生成后再通过对应阶段门。
- `competition` 仅记录关键输入输出的摘要用于识别变化，不增加全量目录扫描或 HMAC；`audit` 保留原有全量哈希、签名与独立复核。

### 档位、赛事与论文审查

- `profile` 控制过程强度，`venue` 控制具体交付规则。总控、契约、写作、审稿、终审和安装运行时读取同一份解析结果。
- 未指定赛事采用通用报告；CUMCM 明确选定后才应用国赛规则。其他赛事保留已有配置能力，具体限制来自用户模板或实施时核验的官方文件，缺失限制不猜测。
- 取消正文、公式、图表、文献数量的默认硬门槛，按逐问回答、推导、验证和必要来源检查。明确项目要求的数量仍可执行，并标明要求来源。
- 优化检查仅用于优化子问题，不强制预测、评价和机理题出现“目标函数”“约束”等词语。
- `competition` 使用精简证据指针；`audit` 才要求完整注册表。正式稿不要求出现 `[claim:ID]`、状态码或后台登记内容。

### 接口与兼容

- 新技能契约版本为 1.5，补充赛事条件与通用 `layout_validation` 角色。旧 1.1—1.4 契约继续按各自规则读取，CUMCM 兼容路径接受旧 `cumcm_layout_validation`；未知版本明确拒绝。
- 状态格式升级至 1.2，保留旧状态读取；旧项目缺少赛事时，在正式推进前要求显式选择，不把历史记录默认为某个赛事。
- 同步契约 Schema 与可选字段、条件角色；保留旧图表调用与元数据读取，新增图型不会改变旧入口的语义。
- 目录数量与能力矩阵从实际注册表生成，更新 skill 中过期的数量说明；验证文档、包、安装 skill 的版本与来源一致。

## 5. 实施批次、测试和验收

### 批次 A：校验基础与高频图复用

完成阶段门、审稿顺序、回退、档位/赛事贯通和数量门槛修复。核对已有高频图的实际数据映射、气泡大小、比例分母和术语，补充用途示例。新增失败与兼容测试，不以匹配指令文字作为行为验证。

### 批次 B：P1 实用图型

依次完成矩阵迷你折线、两种极坐标堆叠模式、人物阵列/轮廓比例、年度日历布局、明确的相关与协方差热图。复用现有风格、导出和视觉审核；更新相关 skill 交接及图型路由。每个入口同时提供字段规范、一个标记为模拟的预览及可重跑代码。

### 批次 C：P2 组合图

抽出有限的矩阵单元格与日历布局辅助函数，完成饼图矩阵、日历小图、保存拟合曲线的绘制和频次气泡矩阵。复用基础渲染能力，不开发通用拖拽布局或仪表板框架。

### 批次 D：完整项目与安装验证

以现有供应商案例验证 CUMCM 完整交付，需求预测与排队案例补充题型验证；示例数据如实标记。再执行通用报告、局部绘图和图表改色的回归，确认没有误触发全项目流程或国赛要求。在临时安装目录验证仓库外调用，最后更新这 8 个数学建模 skill，不覆盖无关技能。

### 必测场景

1. **数值与编码**：小规模已知数据检查堆叠和归一化、扇区比例、图标余量、气泡面积、相关与协方差；图内数值必须能回到源结果。
2. **时间与矩阵**：跨年、闰年、缺失日、重复日、空单元格、异长序列、错误维度；验证日历定位与共享尺度。
3. **异常数据**：负组成、零总量、非有限值、常量相关变量、未声明区间、排序或单位不一致；非法输入明确报错，合法的缺失状态正常呈现。
4. **统计真实性**：无真实区间时不绘制区间，不把频次当独立样本量，不把外推或模拟预览称为验证结果。
5. **执行闭环**：文件齐全但验证失败时不能就绪；回退保留历史、使旧输出过期；重算后正确恢复，审稿与阶段推进顺序可实际执行。
6. **兼容**：旧入口与新入口中英文名称、formal/preview 模式、旧契约、旧状态、安装后依赖和 Schema 验证。
7. **成品检查**：每种新增图型的 PDF/SVG 和 PNG 在最终尺寸下检查中文、裁切、图例、数字、灰度识别；稠密图可采用有记录的数据层栅格化。必要时拆页或改布局，不无限缩小文字。

验收按“可运行、数据语义正确、已看过成品、已验证论文插入”分别记录。注册成功或测试通过不自动把全目录标为适合论文。实施后运行相关测试、静态检查及 CI 要求的检查；已有失败与本轮新增问题分别记录。
