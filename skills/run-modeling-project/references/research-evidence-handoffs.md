# 从数据到论文的证据交接

将 Nature Skills 的可迁移做法放进现有数模阶段，保留当前 profiles、算法库、中文写作与竞赛交付规范。单图、局部修改和小范围检索仅采用相关部分，不强制启动完整管线。

## 各阶段交接的增量

| 阶段 | 交接时需补足的信息 | 主要借鉴 |
|---|---|---|
| 文献 | 具体支持哪条主张、来源定位、全文/摘要/元数据层级、参数迁移条件 | academic-search、paper-card、ref-verifier、literature-pipeline |
| 数据 | 独立分析单位、依赖结构、数据版本/访问方式、区间含义 | statistics、data |
| 选模 | 哪种证据能区分候选或推翻主张，主张强度是否超出可得证据 | paper-card、reviewer |
| 求解 | 实际运行版本/种子/失败记录，观察、推导与解释分别交接 | experiment-log、statistics |
| 图表 | 每个面板的证据作用、连续量与对象身份分别编码、成图复查状态 | figure |
| 写作 | 规范术语/单位/精度、独立可读图注、证据强度对应的措辞 | writing、polishing、shared |
| 审查 | 稿件和证据双定位、影响与最小修复、实际修改后的复核 | reviewer、response、shared |

记录可直接补入现有结果、图表契约或 handoff；上述信息不是一套新的强制文件格式。

## 用户已明确的图表偏好

新建或获授权改图时，功率/能量热图优先深红—橙—金黄，避开近黑低端与近白高端；保存参数点亮色填充配深色粗描边；类别与曲线使用清楚饱和色，并保留线型、标记和灰度辨识。统一字体与对象语义，不统一成浅蓝浅绿的模板。具体执行由 `make-model-figures` 的配色和功率图参考负责。

审查意见或 skill 更新不触发对现有图的重绘。后续用户改变偏好时按当次要求更新，不把波浪能配色推广到残差、相关、地图等不同含义的图。

## 适配边界

- 源库的期刊尺寸、图注字数、字体下限及排版经验不能当作数模比赛官方要求。
- 源库不成为运行依赖；保留项目已经使用的 Python/R 与算法接口。无法运行的自动检查记为未执行。
- 不继承“统一低饱和”“每图只能同一主题”或强制主图面积比。视觉显著性由真实证据和物理量含义决定。
- 不根据误差线重叠判断显著性/等效，不根据 Crossref 单次失败判断文献伪造。
- 演示文稿、专利、下载器、外部推送和自动化不属于数模核心阶段；只有对应任务需要时再使用相应能力。

本参考为阅读 `nature-skills` 本地材料后的独立蒸馏，没有复制其程序或图形资产，也不将其研究经验声称为出版官方标准。
