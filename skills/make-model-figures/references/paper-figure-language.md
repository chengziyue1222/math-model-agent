# 数学建模论文的图形语言

先为一个结论选证据形态，再绘图。每幅正式图都应在插入前说明“为何需要该图”，在图后说明趋势、机制或限制；没有明确结论的图不进入论文。

| 信号 | 优先图形 | 必须展示 |
|---|---|---|
| 多题依赖 | 一张总体技术路线图 | 输入、共用内核、分支、验证和输出；不塞公式。 |
| 几何/机理 | 几何或变量关系示意 | 坐标、方向、变量与约束来源。 |
| 动态过程 | 2×2 或 1×3 多时刻快照，加一张趋势图 | 统一坐标尺度、时刻和关键状态。 |
| 临界事件 | 全局图 + 局部放大/嵌入图 + 事件函数 | 阈值、事件位置、左右状态或括号。 |
| 参数阈值 | 响应曲线或可行域 | 基准点、边界、可行/不可行区域。 |
| 不确定性 | 灵敏度/情景图 | 参数范围、核心输出、是否跨过决策阈值。 |
| 数值精度 | 收敛或独立对照图 | 迭代或步长、停止准则、独立复核。 |

版面原则：颜色服务于对象语义和物理量，重要曲线和类别保持清楚饱满，辅助带和网格适当减弱。功率/能量图可用深红—橙—金黄形成重点；不把白底、细线和低饱和捆绑为学术图模板。单图、双图、四宫格和主图加 inset 都可用；一页不塞四张不可读的小图。正式 PDF 中正文标注、坐标和图例常用 8–9 pt，当前项目审查下限为 7 pt；拥挤时增加高度、换行或拆图。
