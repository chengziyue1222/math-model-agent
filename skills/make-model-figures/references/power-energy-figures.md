# 功率与能量图：保留暖色张力，保证全区间可读

适用于非负功率、能量、耗散强度的参数响应图，以及连续底图上的保存参数点。此偏好来自用户对波浪能图的反馈；不推广为所有学科、所有物理量的统一风格。

## 图形决策

| 对象 | 优先做法 | 核对内容 |
|---|---|---|
| 非负功率/能量 | 深红 → 橙 → 金黄连续色标 | 低端不近黑、高端不近白；整个值域仍有可辨层次 |
| 有正负含义的净输出/偏差 | 围绕物理零点或基准的发散色标 | 中点、上下限、符号和单位明确 |
| 保存参数点 | 亮色填充 + 深色粗描边；形状和文字说明身份 | 保存点不自动改名“最优点”；用保存坐标定位 |
| 参数曲线/类别 | 饱和蓝、橙、朱红、深绿等明确色；线型/标记冗余 | 同一对象全文稳定；橙与朱红仍需非颜色编码 |
| 图例与色条 | 布局预留独立空间；必要时共享图例或直接标注 | 不挡高值区、边界、误差带、参数点或其他有效数据 |

“视觉张力”由真实梯度和色彩层次体现。重配色默认保留数据、网格、参数范围、线性归一化及已有比较范围。确需改用 log、PowerNorm、平滑、插值或裁剪值域时，应有科学理由，记录并标注，不能借此制造快速增长。

## Matplotlib 实施示例

下面是可嵌入现有绘图代码的样式片段，不生成示例数据，也不是已注册的算法主题。`ax`、`X`、`Y`、`P`、保存点坐标、单位及 `vmin/vmax` 均来自当前任务的已保存结果或已声明比较范围。

```python
from matplotlib.colors import LinearSegmentedColormap, Normalize

# 按低值到高值排列。适合作为起点，仍需对实际数据做成图复核。
warm_stops = ["#7F1515", "#B52A1D", "#DD5125", "#F18432", "#F5BC4B"]
power_cmap = LinearSegmentedColormap.from_list("power_warm", warm_stops, N=256)
power_cmap.set_bad("#B8B8B8")  # 缺失/未计算单独说明，不能当作零功率
power_norm = Normalize(vmin=vmin, vmax=vmax, clip=False)
mesh = ax.pcolormesh(X, Y, P, cmap=power_cmap, norm=power_norm, shading="nearest")
saved = ax.scatter(saved_x, saved_y, marker="*", s=100,
                   facecolors="#FFF2B2", edgecolors="#202020",
                   linewidths=1.25, zorder=5, label="保存参数点")
# 用预留的 legend/colorbar 区域放置说明，并在最终物理尺寸检查。
```

`s=100` 的单位是 pt²，描边单位是 pt；二者仅为起始值。缩小后应仍能认出星形和边缘，且不大到遮住局部变化。深色底图依靠亮填充，金黄底图依靠深描边；若低端轮廓仍不清，增加窄亮色外晕或改用圈点组合，并复查遮挡。

优先修复色标、描边、图例位置这三个已知缺陷，不默认更换图型或把所有图改成同一暖色。类别曲线不必跟随热图使用红橙黄。

## 对接现有算法包

- `get_modeling_palette()` 仅接受已注册主题。不要传入 `power_warm`、`custom:power-energy` 等不存在的主题名。
- 保留已有字体/尺寸配置，在具体 `pcolormesh` / `imshow` 对象上设置上述 cmap；若使用模板，应在理解其返回的图层后修改对应 ScalarMappable，并保证色条引用同一对象。无法明确映射时，直接按契约构图。
- 正式契约可用现有支持的 `theme_name="custom:power-energy"` 记录自定义方案；这不会注册主题。准确色值、方向、归一化类与范围、对象样式保存在绘图代码和随附设计记录中，并通过契约的 `plotting_code` / `data_transformations` / `design_brief.color_roles` 引用或说明。不要假设 `.figure.json` 自动提取所有 artist 样式。
- 比较相同物理量的面板共享色域；不同量独立设色条和单位。不默认逐列归一化，不将无效区和最低值混色。

## 验收

1. 比较调整前后的源值、极值位置和参数点坐标，确认变化仅在已声明的视觉编码。
2. 在色条低、中、高区间检查细节、明度顺序和保存点轮廓；检查真实曲线在交叉处的线型/标记。
3. 打开最终物理尺寸校样，检查高值区是否自然突出、图例和色条是否避开有效数据。
4. 查看灰度版本；条件允许时查看常见色觉缺陷模拟。没有实际执行的检查记为未检查。
5. 记录尚未解决的局限；不得仅凭色值表宣称“全背景可见”或“色盲友好”。
