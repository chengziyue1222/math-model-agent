# 常见视觉问题 → 修复方法 → 适用条件

| 视觉问题 | 修复方法 | 适用条件 |
|---|---|---|
| 长中文标签 | 横向点图；按语义换行；预留左边距 | 类别比较，保持名称完整；默认审查下限7 pt，拥挤时重布局 |
| 类别过多 | 按问题分面或分组；正文摘要、附录完整列表 | 说明分组依据；不能无声删除类别 |
| 曲线重叠 | 线型/标记冗余；直接标签；共享轴分面 | 相同对象全文保持样式；不可人为移动真实数值 |
| 密集散点 | 栅格化点层、透明度；必要时hexbin并登记聚合 | 保留全部观测；密度图需给出bin口径 |
| 标注贴边 | 增加显示边距、向内偏移、描边 | 不移动数据坐标；阈值/最优点需查源值 |
| 图例遮挡 | 布局中预留上方或右侧空间；单曲线删除冗余图例 | 轴内图例仅提示人工检查，不能自动判遮挡 |
| 色条拥挤 | 为色条留专门空间；适当减少刻度；统一共享色域 | 同一变量共享；不同变量不要强行共享 |
| 多面板冗余 | 一面板一证据；缺输入就删面板并记原因 | 不用伪造区间或重复运行来填版面 |
| 最终尺寸字号过小 | 从目标mm创建；减少文字/面板；增加独立图 | 当前竞赛默认≥7 pt，常用8–9 pt，可由模板覆盖 |
| 浅背景上白色标记 | 深色描边、对比色填充、直接说明含义 | 连续色图叠加参数点；灰度下仍检查轮廓 |
| 大片低值难辨 | 选择明度连续、两端留有细节的色板；功率图可用深红到金黄；保留原线性范围 | 不能用未经说明的log、平滑或插值制造结构 |
| 所有图显得粉灰、缺乏重点 | 重要曲线提高饱和度和可见线宽，区间带保持浅色；按物理量选连续色标 | 不改变数据，也不把“鲜明”等同于增加颜色数量 |
| 高值近白，白星消失 | 最高色停在金黄；亮色实心标记配深色粗描边 | 色条两端和中段均检查；保存点与最优点分别命名 |

不要用 tight 裁边修复正式尺寸；在最终尺寸上调整布局后重新导出并查看实际文件。
