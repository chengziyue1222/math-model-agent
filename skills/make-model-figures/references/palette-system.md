# 语义配色系统

先确定颜色表达对象身份还是数值大小，再选色。类别、连续量和正负偏离分别设计；同一对象跨图保持语义和样式映射。统一字体、术语和对象含义，不要求所有图使用同一组浅色。

## 选择顺序

1. 当前用户要求和已经确认的对象语义优先；不要为追求“学术感”自动降低饱和度。
2. 功率、能量等非负强度优先考虑深红—橙—金黄；详见 [power-energy-figures.md](power-energy-figures.md)。有正负方向的净功率、残差、变化量用有意义中点的发散色标。
3. 重要曲线和类别优先采用清楚的蓝、橙、朱红、深绿，并分配线型/标记。示例颜色为 `#0072B2`、`#E69F00`、`#D55E00`、`#006B4F`；它们是起点，不是已通过所有色觉测试的保证。不要用这些类别色拼成连续色标。
4. 淡色主要用于区间带、辅助情景和背景。只在用户明确偏好或数据任务适合时使用整套柔和主题。
5. 项目旧配置中的 `muted-modeling-v1` / `modeling-default` 是兼容默认值，不代表本次偏好。后续授权绘图时在该图的配置或 artist 上显式覆盖；更新 skill 本身不触发批量重绘或改写项目配置。

## 内置主题

通过 `get_modeling_palette(name)` 获取。完整、可执行的色值以 `algorithms.sci_figures.MODELING_PALETTES` 为准。

| 主题 | 适用场景 | 视觉特点 |
|---|---|---|
| `nature-accessible` | 默认首稿、关键类别比较 | 高辨识、色盲友好的蓝/绿/橙/紫核心 |
| `modeling-default` | 继承已有论文的旧配色时 | 低饱和蓝绿；新图按任务另选，不作为审美要求 |
| `soft-academic` | 明确要求淡雅展示时 | 柔和蓝粉；关键边线仍需足够深 |
| `aquifer-recovery` | 环境、气候、水资源、恢复轨迹 | 蓝绿为主、暖色作为情景强调 |
| `electrochemistry` | 材料、过程、能源、环境监测 | 冷蓝与珊瑚红的清晰对照 |
| `literature-clinical` | 人群、风险、响应、文献型比较 | 稳重蓝绿、陶红和金色 |
| `sage-methods` | 方法流程、多模态与机制图 | 鼠尾草绿、蓝灰和柔和橙色 |
| `quiet-atlas` | 密集总览、地图和解释图 | 安静蓝灰，适合较大信息密度 |

若论文已有稳定配色，优先继承其语义映射；不要为了使用主题而打乱读者已经建立的颜色认知。

## 角色规则

- `categorical`：按稳定对象名绑定颜色，不随数据排序重新分配；是否将基线置灰取决于它在本图中的证据作用。
- `accent`：每幅图只承担一个预先声明的强调含义，如最优方案、风险越界或关键阈值。
- `grey`：参考组、非重点个体、历史轨迹或上下文。
- `sequential`：表示有序大小，感知明度沿数值方向连续变化；可以低值浅、高值深，也可以低值深、高值亮。功率热图允许后者，需用带单位的色条明确方向。不要强制所有连续量“越大越深”。
- `diverging`：只能表示相对有意义中点的正负偏离。

默认每面板使用 2–4 个高辨识类别色。超过 6 类时优先分面、排序、直接标注或使用层级分组，而不是继续增加相近色。

## 无障碍与灰度

- 红绿不得成为唯一差异；关键类别同时使用线型、标记、排序、分面或直接标签。
- 文字保持近黑色，不用彩色文字代替图例色块。
- 置信带和背景点用 `alpha=0.18–0.35`；焦点线和焦点标记保持不透明。
- 灰度预览中若关键组不可分，先修复冗余编码或明度差，再交付。
- 连续色标检查低、中、高区间的细节和明度顺序；不把顺序色板的色名或端点对比当作感知均匀性的证明。
- 保存参数点、候选点与已验证最优点分别命名。热图上使用亮色实心标记和深色可见描边；在色标两端和中段逐一检查，不能默认白星在任何底色上都可见。
- 用户提供十六进制颜色或参考图时，先建立新的语义顺序；重配色不得改变数据、统计、图型或显著性标注。
