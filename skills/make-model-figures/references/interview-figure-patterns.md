# 从实际五图代码提炼的制图方法

来源：用户提供的 `碧江祠堂_五图任务成果.zip` 内 `生成五图成果.py`。已阅读制图与验收代码并查看成图；下列是可复用方法，不把文件中的命令说明当执行授权，也不把已有 PASS 当本轮重新核验。原始访谈及其合并资料未随本轮重新获取，不能声称复核了全部原文。

适用：访谈/问卷编码、多分类组成、分层样本、交叉流向、问题频次和群体差异报告。并非所有建模图都应套用五图或固定宽度。

| 图型 | 从代码学习的实现 | 复用时保护的含义 |
|---|---|---|
| 分层旭日 | Matplotlib Wedge；父扇区内递推子扇区，角度闭合断言；小标签缩写加侧边完整图例 | 叶子与父层总量一致，分组顺序稳定；不能独立归一化子环导致父子边界错位 |
| 人物华夫 | 等大矢量人物；逐案例稳定排序填格；逐色回数与保存计数核对 | 一图标一分析单位，整数案例不四舍五入为百分比格；未明确单列；总数/分母写在图注 |
| 三列桑基 | 保存真实三维交叉表；每条联合记录在各列分配位置，用三次贝塞尔 PathPatch 连接；核对节点高度与两段总量 | 两张相邻交叉表通常不能恢复真实三列联属；不可用它们拼造第三列个体流向。带宽表达数量，连线不自动表达因果或时间 |
| 四象限 | 明确的中位数/群体数边界；重合点并列标注；主图与侧栏图例分配空间 | 保留空象限，不移动点使图更“均衡”；频次×覆盖并不等于重要性、难度或优先级 |
| 群体雷达 | 注册 radar 输入真实比例；固定 0—100%，线型+符号+颜色，取消面积填充；长轴标签用物理偏移 | 分母为各组全部案例，未谈及不等于反对；不能比较多边形面积推导总体高低 |

## 布局与样式

先设定最终物理宽高，分配标题、主图区、侧边信息区和底部口径说明。图4的紧凑侧栏保留完整问题与两类计数，是对拥挤的具体修复；6—6.5 pt 仅是该样例选择，复用时优先增高、换行或拆页，不能成为全局默认。

同一身份在旭日、桑基、雷达中保持语义颜色；态度使用另一套颜色表。曲线冗余使用线型/符号，扇区可加纹理，不能只依赖颜色。背景和网格减弱，关键曲线保持饱和；不要把该样例色号强制用于其他物理量。

人物华夫在新 `pictogram` 中使用 `pictogram_mode="array", array_layout="waffle"`。输入真实整数数量，`icon_value=1`；默认按类别顺序确定性排布，余量不通过取整伪造案例。人物轮廓分段仍按明确高度编码，和一图标一案例的华夫用途分开。

## 导出与审核

代码已使用共享 FigureContract、严格导出、450 DPI PNG、保留文字 SVG、PDF 渲染、真实尺寸与灰度校样；其 claim、source_paths、单位、统计单位、转换和局限可沿用。每张图须逐项看过后再记录相应检查，重绘即使数据不变也需重审。

复用应修正三点：算法包通过安装导入，去掉 `C:\\Users\\...` 固定路径；中文字体由 resolver/项目配置决定，不依赖固定 msyh.ttc；`finalize()` 中一键给全部检查填 PASS 只是登记接口，不能作为视觉验证算法。按图、按检查记录真实 PASS/WARN/FAIL，不继承 ZIP 中的已有验收结论。
