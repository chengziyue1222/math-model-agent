# 科研论文图表的样式与逐图验收

`get_figure(name)(data=saved_results, config=figure_config, mode="formal")`：数值输入与样式配置分开。显式尺寸/字号参数优先于 `config`，项目配置优先于内置默认；解析结果保存在既有 `.figure.json` 的 configuration 中。同一个渲染上下文控制创建时尺寸、配色和字号，不依赖绘图后缩放画布。

新图默认 `cumcm-research`，保留旧主题。150 mm 常用宽度，正文8.5 pt、刻度/图例8 pt、标题10 pt、面板9 pt，默认审查下限7 pt；这些是本库设计默认，不能称为竞赛官方要求。75 mm图需要改变面板排列和标签换行，并重新检查；明确给出的高度保留，缺省高度按图型与密度安排。

颜色区分类别身份与连续量：相关色域固定−1到1，常数列显示未定义；残差使用零中心发散色板；数量使用连续色标。项目的重要对象在 semantic_styles 中绑定 color/marker/linestyle，保存后跨图复用。显式 group_colors/cmap 保留。组成增加纹理、描边或直接标注，灰度仍须实际查看。

图例、色条与口径说明占独立空间。长标签保留全文并换行；多面板可纵排，不能静默删类别、点、日期或用缩字隐藏拥挤。超过最大高度仍不能清楚表达时，拆图并保存完整对应关系；不能宣称拥挤案例已通过。

每个专用入口各有普通、长中文标签、密集成品；每个别名核对目标、数据与行为。复用 schema 3 的 programmatic_audit / visual_review / completion_status，不新增平行PASS台账。分别查看 PNG、矢量渲染、带实际尺寸的PDF样张、灰度与源数值。程序通过只说明对应程序检查通过，未看的维度为 NOT_CHECKED。

雨云图应同时显示半密度、四分位箱线和全部原始点；常数/单点组不估计密度。气泡按面积编码，人物余量按可见面积，组成分母与零总量明确，区间注明实际算法与样本单位。修复统计错误时保存数值对照并重新生成依赖成果，不能把统计改变称为纯美化。

参考稿按实际PDF页码和印刷页码分别定位。只有全国奖身份已核实且正文实际可读的论文计入国奖研读完成数；文件名、官方展示编号和第三方“国一”标签不能独立证明具体获奖等级。设计参考与模型事实来源分开，参考题解的数值不进入实战求解。

矩阵长标签按最终字体的真实边界检查，拥挤时换行或转动完整刻度，不缩小文字或删除变量。发散热图用实际数值或正负符号补充灰度表达，阈值标记同时说明阈值。环形热图一格对应一个真实圆弧，避免矢量细分接缝制造不存在的结构。

流程图按文字框的实际边界连接箭头；长边注可使用完整对应表，必须保留起点、终点及原注释。密集标记同时核查 PDF 中的实际可见性：六边形分箱的负坐标格不能因矢量对象偏移而丢失。程序数组正确不能替代导出成品的检查。
