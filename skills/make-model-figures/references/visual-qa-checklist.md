# 四轮成图质量检查

自动检查负责拦截机器可判定的缺陷，人工视觉复核负责判断科学含义和视觉层级。只有两者都完成，才能称为正式交付。

## 第 0 轮：数据与论证

- 图中每个数、排序、最优解、阈值和显著性标记能追溯到保存结果。
- 样本定义、中心统计量、误差/区间、筛选、缺失值、异常值和随机性已记录。
- 训练、验证、测试数据没有混画或泄漏；预测起点和外推区间清楚。
- 每个面板提供独特证据，删去不影响结论的重复面板。
- `n` 区分独立样本、重复测量、种子/折数和参数网格点；相同证据作用的可比面板使用一致的区间定义，例外要说明。

## 第 1 轮：编码与尺度

- 轴标签含变量与单位；对数、归一化、截轴和反向指标明确。
- 比较面板共享合适的轴域/色域；发散色标的中点有科学意义。
- 小样本显示原始点；误差线和置信带的定义可见于图注或元数据。
- 面积、长度、颜色和三维透视没有夸大差异；双轴只有在不可替代且清楚标注时使用。
- 连续色标的明度方向符合物理量含义；功率图允许低值深红、高值金黄。检查暗端压缩、亮端泛白和缺失区域，不默认“越大越深”。
- SD、SE、置信区间、预测区间、情景包络分别标明；误差线是否重叠不能单独证明显著、无差异或等效。

## 第 2 轮：代码与导出

- 画布从项目目标尺寸创建（竞赛默认150 mm；89/183 mm保留为预设），未在导出后缩小补救。
- 当前竞赛图字通常 8–9 pt，下限 7 pt（模板可覆盖），面板标签统一为 9 pt 粗体；中文字体和负号均正常。
- PDF/SVG 保留可编辑文字，PDF 使用 TrueType；PNG 为 RGB 且至少 450 DPI。
- `.figure.json` 含契约、设计简报、主题、源路径、变换、随机性和审查结果。

## 第 3 轮：实际打开成图

在论文目标尺寸查看 PNG，并至少打开一种矢量主稿：

- 无裁切、乱码、文字/图例/色条重叠、图例遮挡关键数据或超出画布。
- 图例也不能遮住有效的非重点数据、误差带或可行域边界；优先预留位置，不用不透明白框掩盖冲突。
- 参数标记在色标低、中、高区间均有可见填充和轮廓；重要曲线不被过浅配色、过细线条或辅助网格压弱。
- 三秒内能识别核心信息，英雄面板与支持证据层级符合设计简报。
- 白空间足以容纳面板标签、直接标注和色条；没有为填满画布而放大装饰。
- 灰度或常见色觉缺陷下仍能区分关键比较。
- 图与正文、图注、表格使用相同术语、单位、样本量和结论方向。

审查输出使用四种状态：`PASS`（已核验）、`WARN`（需人工判断但不必然错误）、`FAIL`（正式交付前必须修复）。`NOT_CHECKED` 表示尚未执行。不要把未运行的检查写成通过。

配置、可运行最小示例、模板字段及schema 3迁移见 [execution-and-migration.md](execution-and-migration.md)。

## 渲染几何与复核有效期

对具有可比关系的多面板，在最终布局 draw 完成后检查实际绘图区矩形，不能只比较 subplot 网格参数。同排等权面板比较宽高、上下边界与间距；同列比较左右边界和宽度；面板字母检查锚点。可用 1.5 pt 作为初始对齐容差，再按目标尺寸和设计调整；它是局部检查建议，不是官方要求。刻意放大的主图、inset 或色条单独说明，不通过放宽所有容差隐藏局部错误。

当前工具能测量时保存测量结果；缺少自动检查时做渲染后的人工复核并明确方法，不声称运行了源库专属的 PDF 碰撞或面板对齐脚本。边界框相交是待核对信号，不自动等于真实遮挡；裁切、实际遮挡和无法辨识须修复。

修改数据几何、字体、注释、图例、色条或版面后，原渲染检查失效，重新检查受影响面板和整图。纯配色变化也需重新检查灰度、标记对比和视觉层次。不要复用旧哈希上的 PASS。
