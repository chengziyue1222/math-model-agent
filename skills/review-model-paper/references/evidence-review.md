# 有定位、有证据的审查与修订复核

借鉴 `nature-reviewer` 的主张/证据双定位、`nature-response` 的逐项闭环和 `nature-shared` 的一致性复查，适配普通数模自审。无需固定三位审稿人，也不默认新增实验或全文重写。

## 每条实质问题

用简短记录说明：问题 ID、严重程度、稿件位置、源证据位置、影响、最小修复及复核方法。没有页码时用章节、公式、图表或文本定位，不虚构页码。

- **已确认错误**：重算能证明数字不符、图表与源值冲突、定义矛盾或实际裁切遮挡。
- **证据缺口**：主张需要某类验证但材料未提供；说明缺什么、影响什么，不直接称为造假。
- **质量建议**：更清楚的组织、颜色或图注；不要把个人审美升级为官方规范。

严重程度取决于是否影响结论和读者判断，不取决于改动有多容易。若用户只要审查，输出定位与修复建议，不改稿。

## 重点检查

1. 主张是否跨越证据边界：相关→因果、仿真→真实系统、局部→全局、网格最大→已证明最优、单一场景→普遍稳健。
2. 重复测量、参数扫描、种子和折数是否被误当独立样本；SD/SE/CI/预测区间/情景包络是否混用。误差线重叠不能单独判定无差异或等效。
3. 元数据真实的参考文献是否确实支持所引主张；仅摘要可读时是否引用了不可见结果。
4. 摘要、正文、图、表、结论中的同一量能否回到同一源值和统计口径；提升率、百分比与百分点用法是否正确。
5. 多面板是否分别承担必要证据作用；几张指标图是否只是重复排名。
6. 成图是否显示真实梯度、完整色域和清楚标记：功率图的暖色不是缺陷，浅色也不自动代表专业。检查暗部压缩、亮端泛白、白星消失、图例遮挡以及灰度辨识。
7. 图是否在最后一次改动后实际复查；程序 PASS 不能替代最终尺寸视觉复核。

## 授权修订后的闭环

按“问题 → 实际修改 → 新证据/位置 → 已解决或剩余缺口”复核。写了回应不等于已补证据；计划运行不等于已经运行。变化影响数值、单位、结论或分页时，检查对应图表、交叉引用、摘要与附件。未涉及的内容无需为完成表格而扩修。

只有用户要求或当前工作确实授权独立多代理审查时，才使用独立审稿流程；向各审阅者提供相同冻结材料，并在各自完成前隔离其他审查结论。普通自审不依赖此流程。
