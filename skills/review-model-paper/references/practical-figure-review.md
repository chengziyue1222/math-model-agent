# 实用图表与返工审查

逐问核查源结果、验证及正文结论。对极坐标查堆叠/分母/长度或角度标尺；人物阵列查单位图标与余量面积，轮廓查高度标签；气泡查面积与图例偏移；饼图矩阵查共享组序、零总量；日历查闰日、缺失、重复日聚合；相关/协方差查样本口径、常量未定义与单位；回归查保存曲线、真实区间和外推。

不凭文件齐全或程序零退出码认定就绪。检查 quality_validation 的 required checks 和 explicit PASS、求解状态、证据哈希与最终页面。进入 review 仅要求审查输入，审查结果属于 release。发现问题返回最早受影响阶段，给出原因，执行 rewind 后重算依赖并复核。

competition 使用关键证据，audit 增加完整注册与独立审核；venue 读取同一 resolver。通用报告不套国赛规则。公式、图表、文献数量没有默认硬门槛；明确项目要求可以检查，记录来源。机器检查不能代替最终成品查看。
