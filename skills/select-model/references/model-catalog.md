# 模型选择目录

## 快速映射

| 问题特征 | 首选候选 | 基线 | 主要禁用条件 |
|---|---|---|---|
| 多指标排序 | TOPSIS、AHP-TOPSIS、熵权法 | 等权加权和 | 指标方向或量纲不明确 |
| 投入产出效率 | DEA | 比率分析 | 样本过少、投入产出定义不合理 |
| 小样本单调预测 | GM(1,1) | 线性趋势 | 级比检验失败、强周期或突变 |
| 有解释变量的连续预测 | 线性、岭、Lasso、非线性回归 | 均值或单变量回归 | 严重泄漏、样本不足、外推无依据 |
| 时间序列趋势 | 移动平均、指数平滑、增长曲线 | 前值预测 | 时间顺序不完整、结构突变未处理 |
| 资源分配 | LP、MILP、目标规划、NLP | 贪心规则 | 目标或约束无法量化 |
| 黑箱或非凸优化 | GA、PSO、SA | 随机搜索 | 预算不足、解不可验证 |
| 路径与网络 | Dijkstra、Floyd、MST、最大流、匹配 | 简单贪心 | 图定义、方向或权重含义不清 |
| 随机风险与排队 | 蒙特卡罗、M/M/c、M/M/S/k | 期望值近似 | 分布假设无数据支持 |
| 局部交互演化 | 元胞自动机 | 常微分方程或均值场 | 局部规则无法解释或校准 |
| 图像测量 | 分割、边缘、形态学、特征提取 | 阈值法 | 缺少标定、尺度或质量控制 |

## 组合规则

- 预测：主模型 + 朴素基线 + 滚动或留出验证。
- 评价：主观权重 + 客观权重 + 排名敏感性分析。
- 优化：确定性模型 + 多起点或启发式交叉验证 + 可行性复核。
- 仿真：解析近似 + 随机模拟 + 多随机种子置信区间。

## 淘汰问题

对每个候选模型检查：假设能否验证、数据量是否足够、参数能否识别、输出能否回答原题、结果能否独立复核。任一关键条件不成立时，降级到更简单模型或补充数据。
