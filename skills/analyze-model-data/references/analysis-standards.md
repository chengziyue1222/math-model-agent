# 数据分析标准

1. 保存原始数据校验信息，不在原文件上修改。
2. 建立数据字典：字段、类型、单位、来源、允许范围和缺失含义。
3. 区分结构性缺失、随机缺失和采集错误；记录处理理由。
4. 在切分训练/测试集之后拟合缩放、插补、编码和特征选择步骤。
5. 时间数据按时间切分；分组数据按主体分组切分，避免泄漏。
6. 根据任务同时报告主指标、基线、样本量和不确定性。
7. 回归检查残差、共线性和外推；分类检查类别不平衡、校准和阈值敏感性。
8. 多重比较应说明校正方法；因果结论需要识别假设。
9. 固定随机种子并保存软件版本、参数和数据处理日志。
10. 图表和表格必须能由代码从保存的数据重新生成。
